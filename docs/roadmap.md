# BitBuddy Core roadmap

This roadmap describes goals, not completed features.

## Phase 1 — Reproducible prototype

- [x] Basic OLED display tested on breadboard (reported)
- [x] Basic MPU6050 interaction tested (reported)
- [x] Basic buzzer output tested (reported)
- [ ] Publish tested source sketches with wiring and build instructions
- [ ] Confirm electrical schematic and component variants

## Phase 2 — Interactive firmware

- [ ] Integrate expressive eye animations and motion reactions
- [ ] Design non-intrusive sound cues
- [ ] Add input buttons, idle state, and saved device state
- [ ] Add repeatable tests and code review checks

## Phase 3 — Portable hardware

- [ ] Validate battery charging, protection, and power switching
- [ ] Create and test a printable enclosure
- [ ] Test real-world reliability and power consumption

## Phase 4 — Connectivity

- [ ] Prototype BLE interactions between devices
- [ ] Document pairing, privacy, and failure handling
- [ ] Explore mini-games and community-contributed features
